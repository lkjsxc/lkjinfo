# Agent Skills

## Purpose

Trigger-indexed procedures for coding agents. Load one skill per task.

## Table of Contents

- [idea-intake.md](idea-intake.md): user describes a new software idea.
- [contract-design.md](contract-design.md): product, vision, or architecture contracts need editing.
- [implementation-slice.md](implementation-slice.md): build the narrowest source change for a task.
- [test-gate.md](test-gate.md): add tests and run focused verification.
- [debugging.md](debugging.md): reproduce, isolate, fix, and record a bug.
- [refactor.md](refactor.md): behavior-preserving structural change under line cap.
- [ui-slice.md](ui-slice.md): UI work without fake states.
- [api-slice.md](api-slice.md): API or integration work with explicit failures.
- [data-slice.md](data-slice.md): persistence, schemas, migrations, data ownership.
- [maintenance.md](maintenance.md): update this instruction system.

## Format

Each skill uses headings: Purpose, Trigger, Context, Procedure, Checks,
Must Not, optional Handoff. No YAML frontmatter.
