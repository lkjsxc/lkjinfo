# 0004 Honest State

## Purpose

Record the no-fake-data and no-fake-verification rule.

## Context

Fabricated success poisons agent context and user trust.

## Decision

Product paths show real data or explicit real states only. Synthetic fixtures
are test-only. Unrun gates did not pass. Missing evidence is not absence.

## Rejected Options

- Placeholder UI for demos.
- Claiming gates passed without output.

## Consequences

honest-state.md is canonical. Tasks and skills link it.

## Status

accepted
