# Assumptions

## Purpose

Define how assumptions work during idea intake and later sessions.

## Rules

- Use conservative defaults when the user did not specify.
- Never hide an assumption in code or chat only.
- Each assumption must be accepted, rejected, or converted into a task.
- Record assumptions in the table below with a status.

## Status Values

accepted, rejected, open-question, converted-to-task.
