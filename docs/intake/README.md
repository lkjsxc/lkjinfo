# Intake

## Purpose

Convert an arbitrary user idea into goals, assumptions, questions, and tasks.

## Table of Contents

- [raw-idea.md](raw-idea.md): paste or capture the user idea here.
- [assumptions.md](assumptions.md): how assumptions are recorded and resolved.
- [open-questions.md](open-questions.md): blocking vs non-blocking questions.
- [idea-to-contract.md](idea-to-contract.md): mapping from idea items to contracts.

## Flow

1. Capture raw idea in [raw-idea.md](raw-idea.md).
2. Extract goals, constraints, users, surfaces, risks, unknowns.
3. Record assumptions and open questions.
4. Map items in [idea-to-contract.md](idea-to-contract.md).
5. Seed [../execution/traceability.md](../execution/traceability.md).
