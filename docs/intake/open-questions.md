# Intake Open Questions

## Purpose

Track questions discovered during idea intake before contracts exist.

## Blocking vs Non-Blocking

**Blocking:** progress on the current task cannot continue without an answer.
Record in [../execution/open-questions.md](../execution/open-questions.md)
and set task status to blocked.

**Non-blocking:** the agent can proceed with a conservative default recorded
in [assumptions.md](assumptions.md).
