# Scope

## Purpose

Boundaries for what the future product will and will not include.

## Status

waiting-for-idea

## In Scope (Kit Defaults)

- Instruction system files at repository root.
- Contracts under [../](README.md) until app source exists.
- Verification via [../../scripts/check-all.py](../../scripts/check-all.py).

## Out of Scope (Until Intake Says Otherwise)

- Any specific application stack or feature set.
- Fake product behavior or placeholder success UI.
- Requirements that exist only in chat.

## After Intake

Replace placeholders with product-specific in-scope and out-of-scope lists.
Rejected requirements become out-of-scope rows in
[../execution/traceability.md](../execution/traceability.md).

## Changes
