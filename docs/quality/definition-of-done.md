# Definition Of Done

## Purpose

A task is done only when all of the following hold.

## Checklist

- Contracts are updated if behavior or scope moved.
- Source change exists when the task requires implementation.
- Tests or checks exist for the changed behavior.
- Focused gate ran with actual output recorded.
- [../current-state.md](../current-state.md) reflects new status.
- [../execution/traceability.md](../execution/traceability.md) updated if needed.
- Blocker row and task Status agree with evidence.
- [../execution/done-log.md](../execution/done-log.md) entry for completed tasks.
- Handoff names next executable step.

## Not Done

- Gate not run.
- Docs claim implemented without source and tests.
- Next task undefined in current-blockers.md.
