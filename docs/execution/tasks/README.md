# Tasks

## Purpose

Executable task files with explicit read order, gates, and acceptance.

## Template

Every task uses exactly these headings:

- `# <Task Title>`
- `## Purpose`
- `## Status`
- `## Depends On`
- `## Files To Read`
- `## Files To Touch`
- `## Focused Gate`
- `## Acceptance`
- `## Must Not`

Copy [../../../templates/task.md](../../../templates/task.md) for new tasks.
