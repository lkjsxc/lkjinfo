# Operating Rules

## Purpose

Defaults for task sequencing, completion, and blocker handling.

## Sequencing

- Take blockers in dependency order in [current-blockers.md](current-blockers.md).
- Skipping requires written evidence in the task or handoff.
- A task is done only when acceptance evidence exists.
- Never leave the next task undefined.

## When Blocked

Record the question in [open-questions.md](open-questions.md). Either stop
that line or take the next unblocked row if dependencies allow.

## Extra Work

If an agent discovers extra work, add or update a blocker before ending.

## Contradictions

If docs and code disagree, fixing the contradiction becomes the first task.

## Completion

See [../quality/definition-of-done.md](../quality/definition-of-done.md).
